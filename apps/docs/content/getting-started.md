Helmy runs on macOS, Windows and Linux. You don't need an AI account to start: Helmy sets up a free connection on first run, and you can add your Claude or ChatGPT subscription whenever you like.

| System | Builds |
|---|---|
| macOS 12 or later | Apple silicon and Intel |
| Windows 10 or 11 | x64 and Arm |
| Linux | x64 and arm64 |

## Step 1: Install Helmy

1. Download the build for your system from [helmy.ke/download](https://helmy.ke/download).
2. Install it:
   - **macOS:** open the `.dmg` and drag **Helmy** onto **Applications**. There is one build for Apple silicon and one for Intel.
   - **Windows:** run the installer. It installs Helmy for you alone, with no administrator needed, and opens it.
   - **Linux:** install the `.deb` with `sudo apt install ./Helmy-<version>-linux-x64.deb`, or make the AppImage executable (`chmod +x`) and open it.

<Info>
The macOS build isn't signed yet, so macOS blocks it the first time. Go to **System Settings > Privacy & Security** and click **Open Anyway**. You only need to do this once.
</Info>

## Step 2: Set Up Connections

On first run, Helmy walks you through setup:

1. **Connections.** Helmy sets up a free connection so you can start right away. If you have Claude Code or Codex on your computer, Helmy finds them, but leaves them off until you switch them on, so it never spends a subscription you didn't choose.
2. **Chats.** Bring in conversations you already had in those tools, if you want them.
3. **Folders.** Choose where new chats start.

A short tour follows. Replay it any time from **Help > Show the Tour**.

## Step 3: Send Your First Message

Type what you want done and press **Enter**:

*What's in my Downloads folder?*

Helmy picks a connection, does the work, and answers. Each step it took appears as a line under the reply. Click one to see what ran.
