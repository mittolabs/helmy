title: Beside the Chat
description: Use the panels beside a chat to see and steer Helmy's work as it happens.
---

Helmy shows its work next to the conversation, in panels that open as tabs beside the chat or in windows of their own, so you can check a page, a file or a change without leaving the chat.

| Panel | Shows | Systems |
|---|---|---|
| **Browser** | A page Helmy is working on, which it can read and click through | All |
| **Terminal** | A shell in the chat's folder | All |
| **Files** | The chat's folder, with an editor | All |
| **Changes** | What Helmy changed in this chat, side by side | All |
| **Design** | Screens and pages on a canvas | All |
| **Device** | Android phones and emulators | All |
| **Device** | The iOS Simulator | macOS |

## Editing a File

1. Open **Files** from the tray under the message box, or click a file Helmy mentions.
2. Click **Edit file**, make your change, and save.

Helmy sees your saved changes the next time it works in the folder. Code in an answer has an edit button too, which opens it as a draft.

## Checking a Page in the Browser

When Helmy builds or opens a web page, it appears in the **Browser** panel. Helmy reads the page and clicks through it to check its own work, and you can use the page there too.
