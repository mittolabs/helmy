Helmy shows its work next to the conversation. Each panel opens in a tab beside the chat, or in a window of its own.

| Panel | What it shows | Systems |
|---|---|---|
| **Browser** | A page Helmy is working on, which it can read and click through | All |
| **Terminal** | A shell in the chat's folder | All |
| **Files** | The chat's folder. Open a file to read it, or edit it in Helmy | All |
| **Changes** | What Helmy changed in this chat, side by side | All |
| **Design** | Screens and pages Helmy designs, on a canvas | All |
| **Device** | Android phones and emulators | All |
| **Device** | The iOS Simulator | macOS |

## Edit a file in Helmy

1. Open **Files** from the tray under the message box, or a file Helmy mentions in the chat.
2. Choose **Edit file**, make your change, and save.

Helmy sees your saved changes the next time it works in the folder. Code in an answer has an edit button too, which opens it as a draft.

## Use the browser

When Helmy builds or opens a web page, it shows it in **Browser**. Helmy can read the page and click through it, so it can check its own work. You can use the page there as well.
